1. Alcance, decisiones y fuentes

1.1 Qué representa el modelo

RDM 2019 es una envolvente constitutiva uniaxial monotónica para barras longitudinales de refuerzo. Parte de una curva de tracción y modifica la compresión para representar inicio de pandeo inelástico, degradación pospandeo y una resistencia residual mínima.

1

Tracción de referencia

Elasticidad, meseta de fluencia y endurecimiento curvo.

2

Longitud no soportada

La rigidez de estribos determina n, L=n·s y L/D.

3

Compresión RDM

Transición, dos pendientes negativas y piso 0.2fy.

1.2 Uso previsto

AplicaciónUso de este modeloObservación
Momento-curvatura Apropiado como envolvente monotónica de fibras de acero. Coordinar el pandeo con el estado del recubrimiento.
Pushover monotónico Apropiado si la trayectoria avanza sin inversiones relevantes. La deformación de falla requiere una política adicional.
Historia cíclica No usar como modelo completo. No incluye Bauschinger, descarga, recarga ni fatiga.

1.3 Jerarquía documental auditada

  1. Akkaya, Guner y Vecchio (2019): ecuaciones RDM, Tabla 2.
  2. Dhakal y Maekawa (2002): estabilidad y determinación de n.
  3. Salgado y Guner (2014): implementación práctica y ejemplos de L/D.
  4. Código del repositorio: política de dominio, validaciones y outputs.
Errata identificada en el boletín B3 Su primera página imprime keq=k/kt. El artículo ASCE, la página 2 del mismo boletín y todos sus ejemplos usan keq=kt/k. El repositorio implementa la segunda definición.

2. Signos, unidades y ramas

2.1 Convención física exportada

Tracción Deformación εs ≥ 0 y esfuerzo σs ≥ 0.
Compresión Deformación εs < 0 y esfuerzo σs < 0.

Las ecuaciones RDM se evalúan internamente con una magnitud positiva e=|εs|. Al exportar la rama física se asigna σs=-fsc(e) para compresión.

σs (εs) = { ft (εs) si 0≤εs −fsc (|εs|) si εs<0

2.2 Función constitutiva completa

Tracción de referencia

ft(e)= { Ese 0≤e≤εy fy εy<e≤εsh fu− (fu−fy) ( εsu−e εsu−εsh ) P εsh<e<εsu fu e=εsu 0 e>εsu

Compresión RDM con pandeo

fsc(e)= { Ese 0≤e≤εy max{fr, fst [1− (1−fifit) e−εy εi−εy ] } εy<e≤εi max{fr, fi−0.02Es (e−εi)} εi<e≤εii max{fr, 0.75fi−0.01Es (e−εii)} εii<e≤εsu 0 e>εsu

Aplica para L/D≥5, con fst(e)=ft(e), fr=0.2fy y e=|εs|. Para L/D<5: fsc(e)=ft(e).

Unidades y dominio Longitudes en [mm], esfuerzos y módulos en [MPa], y deformaciones en [mm/mm]. La envolvente termina en εsu; fuera del dominio la API devuelve 0.0. Este cierre no representa fatiga.

5. Geometría para calcular L/D

La dirección de pandeo debe definirse antes de contar ramas y barras. El mismo detalle puede producir valores distintos de le, nl y nb en sus dos ejes principales.

Figura 1. Variables geométricas que intervienen en el cálculo.

5.1 Reglas de conteo

  • nl: ramas paralelas a la dirección que restringe el desplazamiento lateral.
  • nb: barras de una cara que comparten esas ramas.
  • le: longitud deformable de la rama, no la dimensión exterior bruta.
  • Gobierno: evalúe ambas direcciones y use la condición que corresponda a la fibra analizada.

7. Envolvente de tracción

Defina e como una deformación positiva. La curva de referencia tiene tres tramos dentro del dominio 0≤e≤epsilon_su.

ft(e)= { Ese 0≤e≤εy fy εy<e≤εsh fu− (fu−fy) ( εsu−e εsu−εsh ) P εsh<e<εsu fu e=εsu 0 e>εsu

7.1 Aplicación al ejemplo

  • εy=0.0024 y ft(εy)=195958.33(0.0024)=470.30 MPa.
  • Entre 0.0024 y 0.0138, ft=470.30 MPa.
  • Entre 0.0138 y 0.1141, P=3.087 curva el endurecimiento hacia fu=659.74 MPa.
ft(0.020)=659.74+(470.30-659.74) [(0.1141-0.020)/(0.1141-0.0138)]3.087 =504.170 MPa

7.2 Tangente útil para un solucionador

Etan=Es en el tramo elástico;   Etan=0 en la meseta
Etan=[(fu-fy)P/(εu-εsh)] [(εu-e)/(εu-εsh)]P-1
Diferencia entre epsilon_su y fractura epsilon_su cierra la envolvente implementada, pero no representa por sí sola fatiga o rotura acumulativa. El modelo devuelve 0.0 fuera del dominio.

9. Envolvente RDM en compresión

Para e=|εs|, calcule primero una magnitud positiva fsc(e). Luego asigne signo negativo al exportarla.

fsc(e)= { Ese 0≤e≤εy max{fr, fst [1− (1−fifit) e−εy εi−εy ] } εy<e≤εi max{fr, fi−0.02Es (e−εi)} εi<e≤εii max{fr, 0.75fi−0.01Es (e−εii)} εii<e≤εsu 0 e>εsu
fst(e) =ft(e) , fr =0.2fy =84 MPa

9.1 Continuidad obligatoria

  • En e=εy, las ramas elástica y de transición entregan fy.
  • En e=εi, la transición entrega fi.
  • En e=εii, el primer tramo pospandeo entrega 0.75fi.
  • Cuando actúa el piso 0.2fy, la tangente se hace cero.

9.2 Evaluación de un punto del ejemplo

Para flexión y e=0.020, fst=ft(0.020)=504.170 MPa, q=1-fi/fit=0.237406 y x=(e-εy)/(εi-εy)=0.804556.

fsc(0.020)=504.170[1-(0.237406)(0.804556)] =407.8700 MPa

El punto físico exportado es (εs,σs)=(-0.020,-407.8700 MPa). Para compresión axial, el mismo nivel de deformación ya pertenece al primer tramo pospandeo y produce -280.6727 MPa.

12. Verificación, límites y diagnóstico

12.1 Lista de aceptación

  • epsilon_y es input y Es=fy/epsilon_y.
  • k y kt están en N/mm.
  • keq se calculó como kt/k.
  • n pertenece a 1...10.
  • L=n·s y L/D=L/D longitudinal.
  • La rama RDM es continua en epsilon_i y epsilon_ii.
  • fsc nunca baja de 0.2fy dentro del dominio.
  • La rama exportada de compresión es negativa.
  • La curva termina exactamente en epsilon_su.
  • La procedencia de cada input quedó registrada.

12.2 Rango reportado

  • 200 < fy < 900 MPa.
  • 10 < D < 36 mm.
  • fu/fy < 2.
  • parameter_p es un input; P=1 se usa solo en el caso especial.
  • epsilon_u > 14epsilon_y.
  • 8 < rb < 56.
  • L/D≥5 para activar pandeo RDM.
Salir de estos rangos genera advertencias, no una recalibración automática. El analista debe justificar la extrapolación.

12.3 Problemas frecuentes

SíntomaCausa probableAcción
L/D inesperadamente grandenb, nl o le se contaron en otra dirección.Redibujar el mecanismo y revisar la cara evaluada.
keq disminuye al reforzar estribosSe invirtió la razón.Usar keq=kt/k.
Error por keq<0.0009Restricción fuera de la tabla n≤10.No extrapolar; revisar detalle o método.

Compresión positiva en CSVSe usó la API de magnitudes, no la respuesta firmada.Usar el ejecutor Stage 2 o signed_compression_response.

Limitaciones actuales El cálculo físico de L/D implementado cubre restricción transversal rectangular. Secciones circulares, losas, ausencia de estribos y detalles no convencionales requieren una estrategia específica. Tampoco se modela automáticamente el desprendimiento del recubrimiento.
