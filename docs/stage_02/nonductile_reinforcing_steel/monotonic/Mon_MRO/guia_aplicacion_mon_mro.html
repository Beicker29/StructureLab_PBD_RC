1. Alcance, decisiones y fuentes

1.1 Qué representa el modelo

`Mon_MRO` es una envolvente uniaxial, monotónica y sin memoria para alambre o malla electrosoldada de baja ductilidad. La implementación calcula la respuesta en tracción entre el origen y el punto último informado por el perfil.

1

Entrada

Propiedades del perfil y controles numéricos.

2

Inversión

Se resuelve σ para una deformación ε prescrita.

3

Salida

Esfuerzo, tangente, metadatos y curva trazable.

1.2 Fuente experimental empleada

La forma funcional corresponde a la ecuación 6 del estudio de Carrillo, Díaz y Arteta sobre mallas electrosoldadas disponibles en Bogotá. El perfil canónico de 6 mm usa el percentil 2 de resistencia última y la deformación última media de la tabla 4.

DatoValor del perfil de 6 mmUso
Módulo teórico, Es200 000 MPaPendiente elástica inicial
Resistencia última P2, fu573 MPaExtremo de esfuerzo
Deformación última media, εu0.0095Extremo de deformación
Exponente20Forma de la transición
Alcance de la evidencia El artículo respalda curvas monotónicas de tracción. No calibra pandeo, pospandeo, respuesta cíclica ni una rama monotónica de compresión para este material.

1.3 Qué no representa

  • No contiene meseta de fluencia ni una rama descendente agregada.
  • No contiene memoria, inversiones, daño, fatiga ni falla de soldaduras.
  • No usa L/D, separación de estribos ni ecuaciones RDM 2019.

2.3 Dominio constitutivo en tracción

0 ≤ σ ≤ fu    y    0 ≤ ε ≤ εu

No existe extrapolación silenciosa. `strain_from_stress` rechaza esfuerzos fuera de [0, fu] y `stress_from_tensile_strain` rechaza deformaciones fuera de [0, εu].

2.4 Diferencia entre fy y fu

La curva constitutiva se define únicamente con Es, fu, εu y el exponente. El modelo no recibe fy_MPa. La resistencia fy,ef se obtiene después como resultado de la idealización bilineal de energía equivalente ASCE/FEMA; no es un parámetro de calibración de la ecuación Ramberg-Osgood modificada.

No confundir dato normativo con dato constitutivo Una resistencia mínima de una norma sirve para aceptación de producto; no sustituye la curva experimental ni autoriza a inventar εu, una meseta o una rama de compresión.

3. Ecuación constitutiva

3.1 Forma implementada

ε(σ) = σ/Es + (εu - fu/Es) (σ/fu)n

La ecuación entrega deformación como función del esfuerzo. En el código, shape_exponent representa n; el perfil publicado usa n = 20.

3.2 Significado de variables

SímboloJSONUnidadSignificado
εstrainmm/mmDeformación unitaria solicitada o calculada.
σstress_mpaMPaEsfuerzo uniaxial de tracción.
EsEs_MPaMPaMódulo elástico inicial.
fufu_MPaMPaResistencia máxima de tracción usada por el perfil.
εueps_umm/mmDeformación correspondiente a fu.
nshape_exponent-Exponente que controla la transición no lineal.

3.3 Comprobaciones de extremos

Origen Para σ = 0, ambos términos son cero; por tanto, ε(0) = 0.
Punto último Para σ = fu, ε = fu/Es + εu - fu/Es = εu.

3.4 Interpretación física

El primer término es la contribución elástica. El segundo agrega deformación no lineal de manera progresiva hasta alcanzar exactamente el punto último. La formulación es monotónica y no almacena estado entre evaluaciones.

4.1 Validación cruzada decisiva

εu > fu/Es

Esta desigualdad garantiza que la escala de deformación no lineal sea positiva. Si no se cumple, la curva no representa una transición físicamente coherente entre el origen y el punto último.

Sin defaults mecánicos ocultos Es, fu, εu y n deben aparecer en el JSON. Los valores no se deducen del diámetro, de NTC 5806 ni del nombre del material.

5. Parámetros calculados

5.1 Deformación elástica asociada a fu

εe,u = fu/Es

5.2 Escala de deformación no lineal

A = εu - fu/Es

Con A, la ecuación se escribe de forma compacta:

ε(σ) = σ/Es + A(σ/fu)n

5.3 Valores del ejemplo de 6 mm

εe,u = 573/200000 = 0.002865
A = 0.0095 - 0.002865 = 0.006635
0.002865elastic_ultimate_strain
0.006635nonlinear_strain_scale
n = 20shape_exponent

5.4 Parámetros obtenidos por idealización

  • fy,ef es la resistencia de fluencia efectiva que satisface la condición de energía equivalente.
  • εy,ef = fy,ef/Eef es la deformación de fluencia efectiva.
  • Ambos valores son resultados calculados y nunca inputs del modelo constitutivo.
  • No se calcula una rama pospico ni una deformación de fractura diferente de εu.
  • No se deduce una capacidad de compresión desde los datos de tracción.
Lectura del punto último εu es la deformación asociada a fu en el perfil. El modelo termina allí; no afirma cómo ocurre la rotura después de ese punto.

6. Inversión numérica por bisección

6.1 Por qué se necesita una inversión

La fuente entrega ε como función de σ, pero el flujo de caracterización solicita σ para una ε prescrita. La implementación resuelve la raíz:

g(σ) = σ/Es + A(σ/fu)n - εobjetivo = 0

6.2 Intervalo garantizado

σinferior = 0    y    σsuperior = fu

Para 0 ≤ εobjetivo ≤ εu, la raíz queda encerrada en [0, fu]. El programa comprueba este encerramiento antes de iterar.

6.3 Algoritmo implementado

1

Inicializar

Definir límites 0 y fu.

2

Partir

σm = (σi + σs)/2.

3

Evaluar

Calcular g(σm).

4

Acotar

Conservar la mitad que contiene la raíz.

5

Converger

Salir cuando |g| ≤ tolerancia.

6

Proteger

Error si se agotan las iteraciones.

6.4 Controles canónicos

ControlValorInterpretación
root_tolerance1×10-12Tolerancia sobre deformación residual.
max_iterations200Límite determinista de iteraciones.

7. Rigidez tangente

7.1 Derivada de la relación ε(σ)

dε/dσ = 1/Es + (A n/fu)(σ/fu)n-1

7.2 Tangente requerida por el material

Et = dσ/dε = 1 / [dε/dσ]

El código evalúa la derivada analítica en el esfuerzo obtenido por bisección. No usa diferencias finitas durante la ejecución.

7.3 Comprobaciones

En el origen Para n > 1, el término potencial se anula y Et(0) = Es.
En el punto último La tangente sigue siendo positiva, pero es menor que Es por la deformación no lineal acumulada.

9. Política de compresión

9.1 Política canónica: unsupported

Con compression.policy: unsupported, cualquier ε negativa produce un error de dominio. Aunque include_compression fuese verdadero, Stage 2 no dibuja una rama que el modelo no soporta.

Redacción obligatoria El modelo Ramberg-Osgood modificado implementado para malla electrosoldada representa la respuesta monotónica en tracción. La respuesta monotónica en compresión no cuenta con una calibración específica para malla NTC 5806; por defecto se considera no soportada.

9.2 Hipótesis simétrica opcional

σc(ε) = -σt(|ε|)

Solo se habilita con los tres controles siguientes:

ControlRequisito
compression_strain_limitPositivo, explícito y no mayor que εu.
justificationTexto no vacío que explique el uso.
explicit_acceptanceDebe ser true.
"compression": {
  "policy": "symmetric_prebuckling_assumption",
  "compression_strain_limit": 0.002,
  "justification": "Verificación numérica prepandeo.",
  "explicit_acceptance": true
}
Naturaleza de la opción Es una hipótesis prepandeo, no una calibración experimental. No representa pandeo ni degradación pospandeo y siempre genera advertencias visibles.
